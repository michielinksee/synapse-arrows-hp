Privacy Policy

Last Updated: October 27, 2026（資料請求・相談フォームと、Cookie を使わないアクセス解析を追記）

Synapse Arrows Pte. Ltd.（以下「当社」）は、当社が開発・運営するプロダクトおよびサービスにおけるユーザーの個人情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。

対象プロダクト・サービス

本ポリシーは以下の全プロダクトに適用されます：

  • KanseiLINK — AEOレーティングプラットフォーム（kansei-link.com）
  • ScaNavi — 日本酒インテリジェンスアプリ（scanavi.app / iOS / Android）
  • Linksee Memory — エージェント記憶MCPサーバー（OSS）
  • Bantou（番頭） — AI自動経理・税務分類エージェント
  • CardWize — AIカード管理プラットフォーム
  • ScaNavi-PC — PC向け家電レビュー・比較サービス
  • ScaNavi-Kaden — 家電インテリジェンスサービス
  • お役立ちツール — synapsearrows.com/tools/ で公開する無料ツール
  • AI映え診断 — お店・会社のホームページの AI 対応の診断（synapsearrows.com/ai-bae-shindan/）
  • 当社が提供するコンサルティング・アドバイザリーサービス

1.4 AI映え診断（synapsearrows.com/ai-bae-shindan/）

無料の診断と、「詳しい診断」のお申し込みでは、次のとおり扱います。診断の処理と記録は、当社が運営する KanseiLINK のサーバー（mcp.kansei-link.com）で行います。

無料の診断:

  • 取得する情報：入力されたホームページの URL と診断の結果（結果のリンクを後から開けるように保存します）、IP アドレスを変換した値（乱用を防ぐため。IP アドレスそのものは保存しません）。メールアドレスなど個人を特定する情報はうかがいません。
  • あわせて、選んだ業種、来た元のサイトのドメイン（どのサイトから来たか。相手のページの場所や検索語は記録しません）、リンクに付いた utm の値（utm_source・utm_campaign）、診断を始めた当社のページを記録します。どの業種・どの経路から診断が使われているかを数えるためで、保存期間は診断の結果と同じ 1 年です。
  • 診断が最後までできなかった時（サイトが時間内に返事をしない・見つからない・掲載サイトのページだった など）は、入力されたアドレスのホスト名だけ（パスや検索語は含みません）と失敗の種類・選んだ業種・来た元を、どのサイトが読み取れないかを調べるために 90 日記録します。
  • 診断は公開されているページと robots.txt だけを読みます。AI のサービスにはお店の情報を送りません。
  • 保存期間：IP アドレスを変換した値は 30 日で、診断の結果（URL を含みます）は 1 年で消します。

詳しい診断のお申し込み:

  • 取得する情報：お店のホームページの URL、メールアドレス、アンケートの答え（業種・地域・規模・お困りごと・使っている道具・ご相談の希望など。「その他」や市区町村の自由記入を含みます）、2 つの同意（診断への同意・集計への同意）、IP アドレスを秘密の鍵で変換した値（元の IP アドレスには戻せず、生の IP アドレスは保存しません）、受付と確認の日時。お名前・電話番号・住所はうかがいません。
  • あわせて、来た元のサイトのドメイン（相手のページの場所や検索語は記録しません）、リンクに付いた utm の値（utm_source・utm_campaign）、お申し込みを始めた当社のページ、無料の診断の結果の番号を記録します（どの経路からお申し込みがあるかを数えるため）。メールアドレスと同じ 180 日で消します。
  • 利用目的：
    • メールアドレスは、お申し込みの確認と診断結果のお知らせにだけ使います。ご案内やメールマガジンの送信には使いません。
    • URL とアンケートの答えは、詳しい診断の材料にします。
    • 集計に同意いただいた場合に限り、アンケートの選択肢を、個人とお店が分からない形で集計します。
    • IP アドレスを変換した値は、乱用の調査にだけ使います。
  • 保存期間：
    • 確認のメールのリンクでお申し込みを確定されなかった場合は、7 日で全部消します。
    • 確定された場合は、診断結果をお送りしてから（お送りしていなければ確定から）180 日で、メールアドレス・URL・IP アドレスを変換した値・自由記入を消します。集計に同意いただいていない場合は、お申し込みの記録を全部消します。
    • 同じメールアドレスへの送信の回数を数えるため、メールアドレスを変換した値と送信の日時を 2 日だけ残します。
  • 預け先（業務の委託先）：
    • Google LLC（Google Workspace・米国）: 確認のメールと結果のメールの送信。当社のアドレス contact@synapse-arrows.com から送ります。メールアドレスとメールの本文を預けます。
    • Cloudflare, Inc.（Turnstile・米国）: 機械による大量の申し込みを防ぐための確認。診断と申し込みの画面で Cloudflare の確認が動き、確認のために IP アドレスと確認の券を Cloudflare に送ります。
    • AI 4 社（OpenAI・Anthropic・Google〔Gemini〕・Perplexity）: 詳しい診断で「AI がお店をどう答えるか」を確かめるために、店名・地域・URL だけを送ります。メールアドレスやアンケートの答えは送りません。
  • お申し込みの際の同意にもとづき、上の預け先に必要な範囲でお預けします。削除のご希望は、下記のお問い合わせ先までご連絡ください。

1.5 資料請求・相談フォーム（synapsearrows.com/contact/）

資料請求・相談のフォーム（英語版の synapsearrows.com/en/contact/ を含みます）から送っていただいた内容は、次のとおり扱います。

  • 取得する情報：会社名・店名、お名前、メールアドレス、業種、サイトの URL（任意）、ご用件（資料請求・無料相談・見積もり・そのほか）、ひとこと（任意）、プライバシーポリシーへの同意。あわせて、送信の時刻、ページの言語、送信元のページ、参照元（どのページから来たか）、リンクに付いた utm の値（utm_source・utm_medium・utm_campaign）を記録します。
  • 機械による大量の送信を防ぐため、フォームの画面で Cloudflare の確認（Turnstile）が動き、確認のために IP アドレスが Cloudflare に送られます。確認の設定は、当社が運営する KanseiLINK のサーバー（mcp.kansei-link.com）から読み込みます（フォームの内容はこのサーバーには送りません）。フォームの記録には IP アドレスを残しません。
  • 利用目的：資料のお送り、ご相談へのお返事、お見積もりのためだけに使います。メールマガジンやご案内の一斉送信には使いません。
  • 保存期間：最後のやり取りから 2 年で消します。それより前に消してほしい場合は、下記のお問い合わせ先までご連絡ください。
  • 預け先（業務の委託先）：
    • Google LLC（Google スプレッドシート・Google Apps Script・Gmail、米国）: 送っていただいた内容の記録と、担当へのお知らせのメール。
    • Cloudflare, Inc.（Turnstile・米国）: 機械による大量の送信を防ぐための確認。確認のために IP アドレスと確認の券を Cloudflare に送ります。

3. AI サービスの利用

当社のプロダクトは、以下のAIサービスプロバイダーを利用してコンテンツ生成・分析を行います：

  • Anthropic（Claude）— テキスト生成、分類、分析
  • Google（Gemini）— 画像認識、テキスト生成

AIプロバイダーに送信されるデータは、各プロバイダーのプライバシーポリシーに従い処理されます。送信データがAIモデルのトレーニングに使用されることはありません（各プロバイダーのAPI利用規約に基づく）。

4. Google API Services User Data Policy

当社プロダクトのうち、Google APIを利用するもの（ScaNavi等）は、Google API Services User Data Policy（Limited Use requirements を含む）に準拠しています。

  • Googleユーザーデータは本ポリシーに記載された機能の提供・改善のみに使用します
  • サービス提供に必要な場合を除き、第三者に転送しません
  • 広告目的には使用しません
  • ユーザーの承認、セキュリティ上の必要、または法的要件がない限り、人がデータを閲覧することはありません

5. データの保存・セキュリティ

5.1 保存場所

  • クラウドストレージ: Supabase（米国）、Vercel（グローバルCDN）
  • 一時処理: AI解析データは処理後に恒久保存しません
  • ローカル処理: Linksee Memory はユーザー端末内のSQLiteに保存（サーバー送信なし）

5.2 セキュリティ対策

  • 全通信のHTTPS/TLS暗号化
  • OAuth 2.0 による認証
  • 定期的なセキュリティ監査
  • アクセス制御とモニタリング

6. 第三者への提供

当社はユーザーの個人データを販売しません。以下の場合に限り、限定的にデータを共有することがあります：

  • AIサービスプロバイダー（上記3項に記載）— 機能提供に必要な範囲のみ
  • AI映え診断の預け先（上記1.4に記載）— 診断とその連絡に必要な範囲のみ
  • 資料請求・相談フォームの預け先（上記1.5に記載）— 記録とご連絡に必要な範囲のみ
  • Vercel Inc.（Web Analytics）— ページの閲覧の集計のみ。個人を特定する情報は含みません
  • 法的要件に基づく場合
  • ユーザーの明示的な同意がある場合

7. データの保持期間

  • アカウントデータ: アカウントが有効な間保持
  • 一時処理データ（画像・メール等）: 処理完了後に削除
  • 利用統計: 匿名化の上、サービス改善のために保持
  • ユーザーはいつでもデータの削除を請求できます

8. ユーザーの権利

ユーザーは以下の権利を有します：

  • アクセス権: 保有データのコピーを請求する権利
  • 訂正権: 不正確な情報を更新する権利
  • 削除権: データの削除を請求する権利
  • アクセス取り消し: GoogleアカウントやSNS連携の解除
  • データポータビリティ: データのエクスポートを請求する権利

9. 児童のプライバシー

当社のプロダクトは16歳未満の児童を対象としていません。ScaNaviは酒類に関するサービスのため、日本国内においては20歳以上の利用者を対象としています。児童から意図的に個人情報を収集することはありません。

10. Cookie・トラッキング

当社のWebサイトおよびWebアプリケーションでは、サービス提供に必要なCookieを使用します。アクセス解析にはプライバシーに配慮したツールを使用し、ユーザーの個人を特定するトラッキングは行いません。 当サイトは Cookie を使わないアクセス解析（Vercel Web Analytics・Vercel Inc.、米国）を使い、ページの閲覧数と参照元・画面の大きさなどを集計します。個人を特定する情報は集めません。

11. ポリシーの変更

本ポリシーは必要に応じて更新されます。重要な変更がある場合は、プロダクト内通知またはメールにてお知らせします。変更後のサービスの継続利用をもって、更新されたポリシーに同意したものとみなします。
